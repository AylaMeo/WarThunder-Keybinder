Controls and devices

View

Side by side keeps the panels in one row, with a scroll bar under them (the mouse wheel scrolls it too). Overlay mode always stacks.
Panel sizes (keys, spacing and text scale together; at 100% a key is the same size on all three)
A panel that is wider than the window scrolls sideways (its own scroll bar when stacked, the row's when side by side). The keyboard can also be set to fit the window: small square keys, the whole board visible at once. Overlay mode ignores these sizes and fits everything to its window.

Keyboard

How big the keys are drawn is under View > Panel sizes.

Mouse layout

The buttons shown on the Mouse panel: what each one sends and where its card sits. Changes apply when you press Save layout.

Hotkeys

These work while the game has focus, so the game never sees the combination you pick here. Click one, then press the keys (needs Ctrl, Alt or Win). Esc cancels, Backspace switches the hotkey off.

Bind editing (off by default)

Whether this is safe to use is not known. Gaijin has not said if a controls file made by another program is allowed, and its rules against "unauthorized modifications" do not say what counts. The app only writes a new file into your Saves folder, which you load yourself with the game's Import from file; it never changes a file the game owns and never touches the running game. No rule or ban report against this was found, but there is no official permission either. Use it at your own risk.
